# 需要去除的短语

## 开头套话

去掉这些开场白。直接说内容。

- "随着...的不断发展/不断进步"
- "在当今社会，..."
- "不可否认的是/不可否认，..."
- "众所周知，..."
- "近年来，..."
- "在...的大背景下"
- "放眼望去，..."
- "纵观历史，..."
- "时代在进步，..."
- "在...日益...的今天"
- "社会在不断发展，..."
- "我们生活在一个...的时代"
- "进入...时代以来"
- "伴随着...的浪潮"

任何"随着"、"在当今"、"不可否认"式的开头都是在铺垫废话。砍掉，直接说正题。

## 强调性废话

这些词不加任何信息，只是在宣布"这很重要"。删掉。

- "至关重要"
- "不容忽视"
- "值得深思"
- "意义深远"
- "举足轻重"
- "发人深省"
- "功不可没"
- "由此可见一斑"
- "缺一不可"
- "不可小觑"
- "弥足珍贵"

## 四字成语堆砌

不要连续堆砌成语当装饰。用一两个精准的词替代。

| 避免堆砌 | 替代 |
|----------|------|
| 日新月异 | 变化快 |
| 翻天覆地 | 改变大 |
| 如火如荼 | 活跃 |
| 层出不穷 | 多 |
| 与时俱进 | 跟上变化 |
| 突飞猛进 | 进步快 |
| 方兴未艾 | 刚开始发展 |
| 蒸蒸日上 | 增长 |
| 欣欣向荣 | 繁荣 |
| 气象万千 | 多样 |

成语本身不是问题。问题是把它们当填充物堆在一起，没有任何信息增量。一个成语够了，或者换成更直接的描述。

## 填充副词

砍掉这些词。它们是空强调，不增加任何信息。

- "非常"
- "真正"
- "确实"
- "其实"
- "无疑"
- "显然"
- "当然"（当填充词用的时候）
- "始终"
- "全面"
- "深入"
- "充分"
- "高度"
- "有效"
- "积极"
- "大力"

还有这些填充短语：

- "从本质上来说"
- "归根结底"
- "众所周知"
- "换句话说"
- "总而言之"
- "综上所述"
- "不可忽视的是"
- "值得注意的是"
- "值得一提的是"
- "客观来看"
- "严格来说"
- "严格意义上讲"

## 空泛的总结

宣布重要性而不说具体是什么的句子。砍掉或者换成具体的。

- "为我们提供了新的思路"
- "开辟了新的篇章"
- "注入了新的活力"
- "带来了深远的影响"
- "将会是...的未来"
- "任重而道远"
- "值得每个人思考"
- "给我们敲响了警钟"
- "打开了新的大门"
- "指明了方向"
- "提供了宝贵的借鉴"
- "留下了深刻的启示"

如果一个句子说某事"重要"/"深远"/"具有划时代意义"但没有说具体是什么，砍掉或者换成具体的。

## 假引用式说教

引用别人说的话来假装有深度。如果引用不能为论点增加具体信息，删掉。

- "正如X所说，..."
- "有一句话说得好，..."
- "俗话说得好，..."
- "X曾说过"
- "古语有云"
- "正所谓..."

## 标点滥用

AI喜欢用感叹号和省略号制造情感。

- **感叹号**：一个段落最多一个，最好是零个。正常陈述不需要感叹号。
- **省略号**：除非真的省略了内容，否则不用。省略号不是制造悬念的工具。

### "陈述加评判"句式

破折号和冒号都会被AI拿来干同一件事：先陈述，再补一句评判。换标点不换结构，味道不变。

| 模式 | 举例 |
|------|------|
| 破折号："X——这是Y，不是Z" | ""令τ为弛豫时间"——这是定义，不是翻译" |
| 冒号："X：这是Y" | 同一个套路，只是标点不同 |
| 标题："主题——补充"或"主题：补充" | "护栏——这些东西不是痕迹" |

改法是重组句子，不是换标点。三选一：把评判并进陈述（""令τ为弛豫时间"是定义，不是翻译"），让评判断句独立，或者删掉评判（多数评判本来就不必要）。

一段里"陈述加评判"出现两次以上就是痕迹。保留：真正的插入语、低频的解释补充。判断看频率，单独一处不算。

## 中式学术腔

用大词代替具体的描述，读起来像论文摘要而不是人话。

| 避免 | 替代 |
|------|------|
| 纵观全局 | 直接说观察到了什么 |
| 深度剖析 | 分析 |
| 全方位解读 | 解释 |
| 多维度考量 | 考虑多个因素 |
| 系统性梳理 | 整理 |
| 全面提升 | 提高 |
| 深入探讨 | 讨论 |
| 高度重视 | 重视 |
| 统筹规划 | 计划 |
| 稳步推进 | 推进 |

## 系动词回避

AI回避"是"字，用"作为"、"充当"、"标志着"把简单判断包装成抽象名词。人写东西没这么绕。

| 避免 | 替代 |
|------|------|
| 作为...的重要组成部分 | 是...的一部分 |
| 充当了...的桥梁 | 连接了X和Y |
| 标志着...的转折点 | 是转折点 |
| 拥有着丰富的资源 | 资源多 |
| 扮演着关键角色 | 很关键 |
| 见证了历史变迁 | 谁在看？让他做具体的事 |

判断方法：能把"作为/充当/标志着/拥有"改成"是"或直接删掉，就改。

## 模糊归因

用不具名的权威背书，回避给出出处。

- "专家认为/专家表示"
- "研究表明/研究显示"（不说哪篇研究）
- "业内人士指出"
- "有观点认为"
- "数据显示"（不说哪个数据）

**替代：** 给出具体出处，或者改成作者自己的判断（"我认为"），或者去掉归因直接陈述、同时去掉绝对化表述。

**注意：** 原文没有给出处时，不要编一个出处。参见 SKILL.md 的防幻觉规则。

## 营销宣传腔

旅游手册和新闻通稿的腔调。

| 避免 | 替代 |
|------|------|
| 坐落于 | 在 |
| 令人叹为观止 | 描述具体看到什么 |
| 独具匠心 | 设计得巧 |
| 巧夺天工 | 描述具体工艺 |
| 享誉海内外 | 有名 |
| 一应俱全 | 全 |
| 别具一格 | 特别 |
| 美轮美奂 | 描述具体外观 |
| 致力于打造 | 做 |

## 假亲密感

假装和读者建立情感连接。

- "让我们一起..."
- "此刻的你，是否也..."
- "相信每个人都有这样的经历"
- "你是否曾经..."
- "试想一下"

## 引导标签

AI喜欢用标签预告接下来要说什么。删掉标签，直接说内容。

- "直觉："
- "思路："
- "直观理解："
- "核心观察是："
- "核心思想："
- "关键等式："
- "关键性质："
- "基本想法是："

这些标签是元评论，在说内容之前先宣布"我要说什么了"。读者不需要预告。直接给出公式、论证或解释，让内容自己说话。

## 同义反复

两个意思一样的词叠在一起。去掉其中一个。

| 避免 | 问题 |
|------|------|
| "所需代价仅需" | "所需"和"仅需"重复 |
| "代价仅需" | 同上 |
| "目前现状" | "目前"和"现状"重复 |
| "免费赠送" | "免费"和"赠送"重复 |
| "人为的故意" | 两个词意思一样 |
| "必须要" | "必须"已经包含"要" |
| "极其高效" | "极其"是填充，"高效"已经够了 |
| "完全解耦" | "完全"是填充 |
| "严格大于零" | "严格"在数学中是精确用法，但AI滥用它当强调词 |

检查方法：删掉修饰词，看意思有没有变。没变就是冗余。
